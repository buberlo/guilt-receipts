# Guilt Receipts

> Your unorganized spending becomes a tiny haunting.

Personal expense tool where every untagged receipt spawns a small ghost.

## Features
- Capture receipts by photo
- Ghosts age in the UI
- Fuse or split ghost amounts
- Exorcise by categorizing

## Stack
- Expo
- SQLite

## Getting started
```
npm install && npx expo start
```
